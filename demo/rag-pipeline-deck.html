Slide 03 · Orchestration

n8n Workflow: Three-Stage Pipeline

A single n8n workflow orchestrates the full request lifecycle — from live data collection to validated output.

STAGE 01

Internet Search & MCP

  • Live web search for market data cash rate feeds
  • MCP calls: Real Open Banking and other APIs
  • Loan product comparison APIs
  • Facts assembled → structured context
STAGE 02

LLM Inference

  • Grounded prompt → Llama 3.2
  • Context injected, not memorised
  • Local Ollama endpoint, zero egress
  • Qdrant retrieval for policy docs
STAGE 03

Guardrails Validation

  • Fact-check against retrieved context
  • Confidence threshold ≥ 0.70
  • Compliance disclaimer injection
  • Fail → regenerate or escalate
customer query→ verified context→ draft response→ validated advice ✓
